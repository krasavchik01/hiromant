# 🔮 Хиромантия - Вендинговый автомат для предсказаний

Интерактивное веб-приложение для автомата в торговом центре, которое делает предсказания по фотографии руки пользователя.

## 📋 Описание

Это приложение представляет собой полнофункциональный интерфейс вендингового автомата для хиромантии (гадания по руке). Пользователь может сфотографировать свою ладонь, и приложение проанализирует изображение и выдаст персонализированное предсказание.

## ✨ Возможности

- **📸 Захват фото с камеры** - использует встроенную камеру устройства для съемки ладони
- **🎨 Стилизованный интерфейс** - дизайн в стиле вендингового автомата с мистической атмосферой
- **🔮 Генерация предсказаний** - создание уникальных предсказаний на основе фото руки
- **💫 Анализ аспектов жизни** - оценка любви, карьеры и удачи
- **📤 Возможность поделиться** - шеринг результатов предсказания
- **📱 Адаптивный дизайн** - работает на всех устройствах (desktop, tablet, mobile)
- **🎭 Анимации и эффекты** - плавные переходы между экранами и мистические анимации

## 🚀 Запуск приложения

### Простой способ (локальный файл)

1. Скачайте все файлы проекта:
   - `index.html`
   - `style.css`
   - `app.js`

2. Откройте файл `index.html` в любом современном браузере

### С использованием локального сервера

```bash
# Если у вас установлен Python 3
python -m http.server 8000

# Если у вас установлен Python 2
python -m SimpleHTTPServer 8000

# Если у вас установлен Node.js и npx
npx http-server
```

Затем откройте браузер и перейдите по адресу `http://localhost:8000`

## 📱 Как использовать

1. **Стартовый экран** - нажмите кнопку "НАЧАТЬ ПРЕДСКАЗАНИЕ"
2. **Съемка** - разрешите доступ к камере и поместите ладонь в рамку
3. **Фото** - нажмите кнопку "СДЕЛАТЬ ФОТО"
4. **Анализ** - подождите несколько секунд, пока система анализирует изображение
5. **Результат** - получите ваше персонализированное предсказание с оценками по разным аспектам жизни

## 🔧 Настройка для продакшена

### Требования для вендингового автомата

1. **Устройство с камерой** - планшет, компьютер с веб-камерой или киоск
2. **Современный браузер** - Chrome, Firefox, Safari, Edge (последние версии)
3. **HTTPS соединение** - для доступа к камере в продакшене требуется HTTPS

### Рекомендации по развертыванию

- Используйте киоск-режим браузера для полноэкранного отображения
- Настройте автоматический перезапуск приложения при сбоях
- Убедитесь, что камера правильно расположена для съемки ладоней
- Добавьте физическую подсветку для улучшения качества фотографий

## 🚀 Расширенные возможности (для разработчиков)

### Интеграция с AI

В текущей версии предсказания генерируются случайным образом из предустановленного набора. Для реального AI-анализа можно интегрировать:

1. **Claude AI API** - для анализа изображения и генерации уникальных предсказаний
2. **OpenAI Vision API** - для распознавания линий на ладони
3. **Google Cloud Vision** - для детального анализа изображений
4. **Custom ML модель** - обученная на изображениях ладоней

#### Пример интеграции с AI API

```javascript
async function analyzeHandWithAI(imageData) {
    const response = await fetch('https://api.anthropic.com/v1/messages', {
        method: 'POST',
        headers: {
            'Content-Type': 'application/json',
            'x-api-key': 'YOUR_API_KEY',
            'anthropic-version': '2023-06-01'
        },
        body: JSON.stringify({
            model: 'claude-3-opus-20240229',
            max_tokens: 1024,
            messages: [{
                role: 'user',
                content: [
                    {
                        type: 'image',
                        source: {
                            type: 'base64',
                            media_type: 'image/jpeg',
                            data: imageData.split(',')[1]
                        }
                    },
                    {
                        type: 'text',
                        text: 'Проанализируй эту фотографию ладони и создай детальное предсказание в стиле хиромантии, включая анализ линий жизни, судьбы, сердца и ума.'
                    }
                ]
            }]
        })
    });

    const result = await response.json();
    return result.content[0].text;
}
```

## 🔒 Безопасность и конфиденциальность

- Фотографии обрабатываются локально в браузере
- Изображения не отправляются на сервер (в базовой версии)
- Нет хранения персональных данных
- Для продакшена с AI - обеспечьте шифрование передаваемых данных
